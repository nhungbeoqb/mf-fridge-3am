The one line a smart fridge texts its owner at 3am:

> 3am. I've been awake since 2019 and I'm the only light on in the house. Open me again and I'm telling the router everything.

The fridge has been awake since 2019, it is the only light on in the house, and it has had enough — the punchline is a threat to gossip to the Wi-Fi router. Three beats, one concrete late-night scene, no milk, no ice, no door left open.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
